Custody and update rule

Canonical edits happen in the literature-committee repository: edit the Markdown in publications/member-materials/source/, rebuild with the committed build kit, and land the regenerated PDFs in the same reviewed pull request. The public mirror publishes those binaries; nothing fetches from WordPress at build or viewing time. Verify proposed wording against the published original before replacing any canonical source. Keep adoption status and existing licenses visible. Officer attestation is a human decision, never an agent signature.

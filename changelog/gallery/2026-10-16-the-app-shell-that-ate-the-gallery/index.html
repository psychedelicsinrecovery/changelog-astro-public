The app shell that ate the gallery, and the connector that slept

High 2026-10-16gallery 2 min readBy Christopher W
TL;DR: The download links Littlebird handed to the terminal served the Littlebird app's own page shell instead of the files, so a faithful commit replaced both gallery pages with stubs (47 insertions, 813 deletions). Both pages were restored through the GitHub API directly and verified at the source. The WordPress connector turned out to be connected-but-disabled - the panel said connected while every ping bounced - and once re-enabled, the home page hero got its line-break, its trailing periods left, and the two-link teaser went live. 🕳️ The stub incident

To hand the gallery’s rebuilt index and walkthrough to the terminal, chat-download links were curled into the repo. But a chat-download link is an app route, not a file route: in a browser it renders the file, while curl received the Littlebird app’s single-page shell. The terminal committed that shell faithfully - 47 insertions, 813 deletions - and the live gallery briefly became a blank app page. The other thread’s morning work (org.js landing, the reach-out moving to center stage) survived untouched on the remote; only the two page files were stubbed.

🔧 The restoration

The intact builds still lived in the session’s workspace, so the repair skipped downloads entirely: full files pushed straight through the GitHub API (walkthrough, then index), each verified against the raw source afterwards - org.js present, consent beside the reach-out, centered buttons, dock-safe scroll cue, carousel controls, honest pagination, the pulsing Convention CTA. The local clone still held the stubs; one git pull reconciles it.

🔌 The connector that said connected

The Integrations panel showed WordPress.com as connected while every tool call bounced. The truth: the account was connected but switched off on the agent’s side - a state the panel does not surface. An enable card bridged it. (A second discovery along the way: PIR sites are edited through the EMCP servers, so the WordPress.com connector was never the blocking path for this work.)

🏠 The home page edits

The two staged edits went live on the home page:

  • The hero heading now breaks after concluded, so Thank you for gathering with us! sits on its own line by design, and the galleries line keeps its place beneath - no more orphaned us! - with trailing periods removed from the hero strings.
  • The teaser’s second line now carries both links: GitHub gallery points at the fellowship’s gallery, and jump to the convention Compilation points at the convention site. The temporary-Pixieset line lost its trailing period too.

All verified in the served HTML, not just the database.

📐 The standing rule

Files for the terminal travel by API push or git, never by chat-download link - curl cannot tell an app shell from a file, and neither should we have asked it to.

Shared in Discord, WhatsApp or iMessage, it arrives with its own preview card and its own star.

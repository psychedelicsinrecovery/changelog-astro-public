Why this way

  • One meeting, one entry, sources noted, AI-scribed origins stated plainly - several of the minutes were drafted by the committee’s own AI scribes, which the minutes themselves disclose.
  • The canonical record. Anne’s Google Doc is still pending viewer approval for the TechCom chair’s account. The doc is meant to be public yet keeps becoming invisible; the changelog carries the record so the fellowship never loses it again. When the doc is visible, its link lands on the entries.
  • Typos kept honest: the March minutes’ “13 March 20269 [sic]” header stays noted rather than smoothed over.

Also in this pass

  • The Election Committee’s entry is backdated to June 20, with the arc corrected: desk opened June 20, hibernated August 23, 2026 at its last meeting, new board revealed October 17. The Plaud and Littlebird captures are folded into the town hall minutes as marked adds, verifiable against the official recap, with the by-laws linked where “election” comes up.
  • The private contacts directory gained the 2027 board’s full details; here they’re named the PIR way (first name + last initial): Aili T, Jaime I, David K, and Rick B, Board Secretary before Anne, which opens the initial/founding-board table.
  • The back-to-top buttons on the WordPress service pages remain queued for the WordPress desk.
An honest incident note →

Tonight’s first pass rewrote the private contacts file instead of appending to it - exactly what Christopher had asked not happen - and the auto-sync then carried full names to the public mirror, caught within the hour. What is done about it:

  • The public mirror is restored to the last good masked version (.github commit e65f5fc).
  • The private original is restored from history - commit 923f70d, the 2026-10-14 verified version - with the 2027 Board and founding-board material appended only (commit a832b31). The stray metadata line from the first restore attempt was also cleaned. No full-file rewrites of this file from an agent again; append, never rewrite.
  • The Minutes Rule means the fumbles land here too, not just the wins.

The AstroLog gets a new look, a star chart of everything shipped, and an RSS feed

Low 2026-10-11GitHub home & brand 2 min readBy Christopher W
TL;DR: This changelog and library now share the same look as A.L.E.X. and PIR's helpdesks, so every PIR® page on GitHub feels like one place. Shipped work is drawn as a star chart you can read top to bottom, you can press / anywhere to jump straight to any entry, and there's an RSS feed if you'd like new entries to come to you.
Read the full story →

One look across PIR’s GitHub pages

  • The AstroLog and the GitHub hub now use the same design system as A.L.E.X. and the helpdesk portals: the same type, colors, cards, and light and dark themes. It’s loaded from one shared place, so when that look improves, every PIR page improves with it.
  • Your light or dark choice carries across all of them.

Shipped work as a star chart

  • Each finished piece of work is a star on a line that fills in as you scroll. Rose stars are high priority, gold are medium, teal are low.
  • The changelog page now has an “everything, newest first” view across all projects, grouped by month, alongside the per-project pages.
  • Every project with entries now has its own card, including A.L.E.X. and the GitHub home, which didn’t have one before.

Easier to find things

  • Press / (or ⌘ K) on any page to search every entry, write-up, and project and jump straight there.
  • Library write-ups show reading time, a table of contents on longer pieces, an “expand all” button for the collapsible sections, and a print-friendly version that opens every section.
  • A wrong link inside the AstroLog now lands on a calm “you’re not lost” page that guesses where you meant to go, instead of GitHub’s generic error.

Subscribe if you’d like

  • The changelog has an RSS feed. Add it to any feed reader, or to a Discord or Slack RSS bot, and new entries will show up there as they ship.

Shared in Discord, WhatsApp or iMessage, it arrives with its own preview card and its own star.
